# TopLet 0.1.17

- Drag a file onto AirDrop to choose a device. TopLet releases the drop target as soon as it handles the drop. If you drag away and release, TopLet also clears the target when macOS misses the final drag event.
- Open Settings → General → Startup to turn Launch at Login on or off. If macOS needs approval, use Open Login Items beside the setting.

## 简体中文

- 将文件放到 AirDrop 上后，TopLet 会先释放拖动区域，再打开设备选择窗口。把文件拖出并松手后，即使系统漏发拖动结束事件，也能继续拖下一个文件。
- 打开「设置 → 通用 → 启动」即可切换「登录时启动」。如果 macOS 需要批准，可以直接点「打开登录项」。
