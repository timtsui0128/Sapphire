# Sapphire Personal 0.1.0 / 个人版 0.1.0

The first release with in-app updates for this personal fork. Install this version once; future signed personal releases can be downloaded and installed from Settings → About → Updates.

- Added a personal GitHub update channel backed by Sparkle 2.10.1. Signed feeds and archives are required; upstream releases cannot overwrite the personal build.
- Added background update checks and optional automatic preparation, with install/relaunch, install-on-quit, cancellation, and lock-screen privacy handling.
- Includes the English / Simplified Chinese language switch: Settings → General → Language, with Follow System as the default.
- Includes the screenshot shelf with batch drag, capture timing and retention settings; Football/F1 and stock watchlists; appearance/glass options; external-display sizing, pin/input, Bluetooth sound and lock-screen fixes.

This release supports Apple Silicon and macOS 14+. The initial updater-enabled version must be installed manually once. Existing data remains in the current Sapphire data directories. Builds are locally ad-hoc signed and are not Apple notarized.
