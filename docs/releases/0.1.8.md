# TopLet 0.1.8 — A new name

## English

- Sapphire Personal is now **TopLet**. App name, menus, onboarding, settings, update notifications and English/Chinese UI use the new name. New downloads contain `TopLet.app`.
- About now shows the maintainer, this fork's source, the original Sapphire project and bundled license notices. Original attribution and GNU AGPLv3 are preserved.
- Existing screenshots, settings, clipboard history and update preferences retain their storage identifiers. Old versions can use the same signed update feed; this release validates delta upgrades from the previous Sapphire bundles.
- Sparkle updates your existing installation in place, so its physical Finder filename may remain `Sapphire.app`. The About page identifies the updated app as TopLet 0.1.8.

Validation: English/Chinese localization and menu checks, update-channel/publisher tests, full Apple Silicon build, and applied delta signature/metadata verification. The running installed app is not moved or replaced by the build/test process. Existing ad-hoc signing and macOS permission limitations remain.
