# TopLet 0.1.14 — Make the split-window target visible

## English

- Approaching the top center with a window now shows “Drag here to split the window.” Enter the visible target and it highlights with “Hold here to choose a layout.” The existing Activation Delay still controls when layouts open.
- Enlarges the target to 320 × 64 points and positions it below the actual menu bar/safe area. The visible target and activation region use the same coordinates on built-in and external displays.
- Keeps the physical top edge for Mission Control. The hint never intercepts mouse input or takes keyboard focus, and disappears on activation, release, cancellation, system handoff and lock. File AirDrop/Clipboard destinations stay separate.
- Includes English/Chinese text, native light/dark materials and a Reduce Transparency fallback. Retains the 0.1.13 drag-sampling fix and the existing signing identity.

Validation includes multi-display trigger geometry, production dwell and silent-event handling, an offscreen native hint's input/focus and privacy behavior, light/dark bilingual renders, localization, file-drop regression checks and full build/signature verification. Actual window dragging and Mission Control require confirmation after installation. This remains a personal Apple Development-signed build without Apple notarization.

- 目标区扩大为 320 × 64 点，随实际菜单栏和屏幕安全区定位；可见目标与真正的触发区使用同一坐标，兼顾内置和外接屏。
- 最顶边仍用于调度中心。提示不拦截鼠标、不获取焦点，在展开、松手、取消、让出系统操作或锁屏时隐藏。文件拖放仍显示 AirDrop／剪贴板目标。
- 提供中英文、系统明暗磨砂材质和降低透明度时的实色背景，保留 0.1.13 的拖动采样修复及固定签名身份。
