# Sapphire Personal 0.1.3 — Open new screenshots in one click

## English

- After Sapphire collects a new system screenshot, the next normal notch click opens File Shelf → Screenshots ahead of Now Playing and remembered navigation.
- Switch directly to Screenshots even when the shelf previously showed Files or AirDrop, and clear a stale file preview.
- A batch of new screenshots requests one click. Once opened or explicitly viewed, screenshot history does not keep overriding normal music navigation.
- Existing Pin, drag, Command-click, and lock/session protections remain in place. Loading history or manually importing files does not request a screenshot shortcut. Collection does not automatically open the notch.

Validated using the production click-routing method and real screenshot collector, native notch click/Pin regressions, and a complete Apple Silicon build. System screenshots must first be saved and collected; the configured floating-preview timing still applies.

## 简体中文

- Sapphire 收到新的系统截图后，下一次普通点击刘海直接进入“文件架 → 截图”，优先于音乐和上次打开的页面。
- 即使文件架上次停在“文件”或 AirDrop，也会直接切到截图，清除旧文件预览。
- 连续多张截图只占用一次点击；打开或主动查看后，旧截图不会持续抢占正常音乐导航。
- 保留 Pin、拖放、Command 点击和锁屏／会话保护。加载历史或手动导入不触发优先级，也不会因截图而自动展开刘海。

系统截图需要先保存并被收集，现有“立即抓取／保留浮动预览”设置仍然有效。检查使用实际截图收集器及生产点击路由，并覆盖原生点击、Pin 和完整应用构建。
