# TopLet 0.1.12 — Keep Mission Control accessible

## English

- To open Snap Zones, pause with a window at the center just below the menu bar. The activation area now sits below the screen's top edge, with the existing configurable delay.
- Keep dragging to the physical top edge to use Mission Control. TopLet cancels pending or open snap layouts, clears the preview and disarms its transparent input area. It stays out of this drag until mouse-up, even if the observed app or display changes.
- A delayed activation timer or mouse-up cannot apply a stale snap selection after handoff. The next drag can activate Snap Zones normally. Settings descriptions explain both gestures in English and Simplified Chinese.
- Retains the asynchronous window-placement fixes from 0.1.11, separate AirDrop/Clipboard file destinations, and the same Apple Development signing identity. This remains a personal test build without Apple notarization.

Validation covers production drag-state/timer behavior, multiple-display geometry, handoff before/after activation, observer replacement, release cancellation, next-drag recovery, and actual disarming/restoration of an offscreen native hover probe. File-drop/clipboard regression checks, localization and complete build/signature checks are also run. Live Mission Control interaction across the user's desktops still needs confirmation after updating.

## 简体中文

- 分屏入口改为菜单栏下方正中的停留区，与屏幕最顶边分开；继续使用设置中的激活延迟。
- 窗口继续拖到最顶边时，TopLet 取消待展开或已展开的分屏，清除预览并停用透明鼠标区域，把操作交给 Mission Control。松手前不再弹出，即使前台应用或显示器发生变化。
- 防止迟到的计时器或松手事件误触发分屏；下一次拖动仍能正常展开。中英文设置说明同步更新。
- 保留 0.1.11 的异步窗口调整修复、文件 AirDrop／剪贴板投放区和同一 Apple Development 签名身份。本版本仍是未经 Apple 公证的个人测试版。

已检查拖动状态与计时、多显示器坐标、展开前后的系统让出、观察应用切换、松手取消及下次拖动恢复；离屏原生窗口验证透明区域确实停用和恢复。同时检查文件拖放／剪贴板、本地化、完整构建和签名。实际跨桌面的 Mission Control 操作仍需更新后确认。
