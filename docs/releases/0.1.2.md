# Sapphire Personal 0.1.2 — AirDrop inside Sapphire

## English

- AirDrop is now an independent tab inside File Shelf, beside Screenshots and Files. Drag items into the panel, choose multiple files/folders, or share clipboard content.
- Remove the separate AirDrop menu-bar icon and its settings toggle, including for users upgrading from 0.1.1. The screenshot selection toolbar still supports batch AirDrop.
- Keep the panel compact, preserve system recipient selection, and retain screenshots when sharing is cancelled. Includes English and Simplified Chinese.
- Show download byte progress and average speed. Reduce excessive Settings redraws during downloads.
- Enable signed incremental updates between compatible builds, with automatic full-archive fallback. The release tool generates patches from the two most recent retained compatible releases and applies each generated patch before publishing it.

**One full update is required from 0.1.0/0.1.1**, whose updater only accepts ZIP URLs. After installing this version, future compatible releases can use smaller incremental downloads. This does not change GitHub's network speed or guarantee a particular download time.

Validated with internal AirDrop light/dark and English/Chinese renders, native pasteboard/drag tests using simulated sharing sessions, real disposable-app delta installation and corrupt-delta fallback, screenshot/localization regressions, and a complete Apple Silicon build. AirDrop tests do not send files to another device.

## 简体中文

- AirDrop 移入 Sapphire 的文件架，与“截图”“文件”并列为独立标签。可以拖入内容、选择多个文件／文件夹，或分享剪贴板。
- 移除独立的 AirDrop 菜单栏图标和对应开关；旧版升级后也无需手动关闭。截图页仍可多选后一起 AirDrop。
- 面板保持紧凑，接收设备由你在系统窗口里选择，取消时保留截图。支持中英文。
- 更新下载页显示已下载大小和平均速度，并减少频繁界面重绘。
- 加入兼容版本之间的签名增量更新；补丁失败时自动改下完整包。发布前会实际应用每个生成的补丁做验证。

**从 0.1.0／0.1.1 升级仍需完整下载一次**，因为旧更新器只接受 ZIP 地址。安装本版后，后续兼容更新可只下载变化部分；实际耗时仍受 GitHub 网络速度影响。
