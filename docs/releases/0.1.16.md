# TopLet 0.1.16 — Display handoff and calls

- Reattach the island to the active desktop after connecting or disconnecting a monitor, waking a display, or changing Spaces. Display preferences, manual hiding, and lock-screen privacy still apply.
- Show detected FaceTime and WhatsApp for Mac calls ahead of background activities such as music. FaceTime can recognize input handled by the system call process. The WhatsApp card shows elapsed time since detection and opens WhatsApp. Detection uses local system audio activity, without recording audio.

## 简体中文

- 拔插显示器、显示器唤醒或切换桌面后，重新定位并显示刘海条。仍尊重显示器设置、手动隐藏及锁屏隐私。
- FaceTime 和 WhatsApp Mac 版有通话时优先显示活动卡片。FaceTime 也能识别由系统通话进程处理的音频输入。WhatsApp 卡片显示检测到通话后的计时，可以点回 App。识别只看本机音频使用状态，不录音。
