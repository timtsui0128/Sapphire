# Sapphire Personal 0.1.6 — Window snapping

## English

- Keep the identity of the window being dragged through mouse release, instead of selecting another frontmost/focused window when the drop is handled.
- Allow the source app's drag transaction to finish, then verify the actual window frame and retry briefly if the move or resize was ignored. A refused layout now shows a message instead of silently doing nothing.
- Use the display containing the selected layout for the final placement, and the pointer's display for its preview. Keep the Dock and menu bar outside the target frame.
- Preserve Command/Escape cancellation through release, avoid snapping while crossing displays with the mouse button still held, and stop pending movement if another drag starts or the session locks.
- Refresh window-drag observation when accessibility trust changes. Missing-permission messages link to the relevant settings page and use the macOS 27 name, **Device Control and Data Access**; older systems still call it **Accessibility**.

Validation: production geometry, frame verification/retry and drag-state code are tested with simulated window writes and inert event monitors; complete Apple Silicon app build and signature checks are also required before publication. These tests cover source-app frame resets, minimum-size rejection, cancellation, release ordering and main/negative-origin/stacked display coordinates. They do not move windows in the installed Sapphire app. Real drag-and-drop behavior and the current app's effective macOS permission still need on-device verification; an enabled entry in System Settings alone does not establish that the running copy is trusted.

## 简体中文

- 拖动时记住实际窗口，松手后继续排列同一个窗口，避免重新选择前台／焦点窗口时选错对象。
- 等原应用处理完松手动作，再移动和调整窗口；读取实际位置与大小，遇到忽略指令时短暂重试。窗口拒绝布局时显示提示，不再静默失败。
- 在所选布局所在显示器上排列窗口，预览跟随鼠标所在显示器；目标区域避开 Dock 和菜单栏。
- 松手后保留 Command／Esc 取消状态；按住鼠标跨屏时不提前分屏，新拖动或锁屏时停止待执行的移动。
- 权限状态改变后重新建立窗口拖动监听；缺失权限时可打开对应系统设置。macOS 27 使用 **Device Control and Data Access（设备控制与数据访问）** 的新名称，旧系统仍称 **Accessibility（辅助功能）**。

验证使用真实几何、位置核验／重试和拖动状态代码，配合模拟窗口写入及空事件监听器；发布前也需完成 Apple Silicon 应用构建与签名检查。覆盖原应用恢复旧位置、最小尺寸限制、取消、松手事件顺序，以及主屏、负坐标和上下排列显示器。测试不操作已安装的 Sapphire。真实拖放及当前应用的有效系统权限仍需在设备上验证；系统设置中的开关已开启，并不单独证明正在运行的副本已获有效授权。
