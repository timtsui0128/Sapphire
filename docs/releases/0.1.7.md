# Sapphire Personal 0.1.7 — Capture & Share

## English

- Drag files, PDFs, or images to Sapphire at the top of the display to reveal an AirDrop drop zone automatically. Release to select a device in macOS. Disable this shortcut in File Shelf settings to restore the regular shelf/device destinations.
- Screenshots start unselected. Manual selections, including deselecting everything, persist across reopening and relaunch; new captures never join the selection automatically.
- Newly collected screenshots copy their image data to the clipboard by default, ready for Command-V in apps that accept images. Turn this off in screenshot settings or the gear menu. Use immediate collection to avoid waiting for the macOS floating preview to finish.
- Historical/imported screenshots do not overwrite the clipboard. Newer captures, manual clipboard changes, pausing, disabling and session locking invalidate pending copies. AirDrop cancellation preserves screenshot retention.

Validation: screenshot collection/persistence and isolated clipboard race tests; native drag, sharing cancellation/retention and privacy checks; pin/input regressions; bilingual UI renders; full Apple Silicon build and signature verification. Tests use isolated folders, named clipboards and mock AirDrop sessions. Actual delivery to an iPhone/iPad still requires trying the chosen device. This version keeps the existing experimental ad-hoc signing; updating may require macOS window-control permission to be refreshed.

## 简体中文

- 将文件、PDF 或图片拖到屏幕顶部的 Sapphire，自动展开 AirDrop 投放区，松手后在系统面板选择设备。文件架设置可关闭快捷入口，恢复原来的文件架／设备目标。
- 截图默认不选中；记住用户上次手动选择，包括取消全选，重开面板或重启后仍保留。新截图不会自动加入已有选择。
- 新收集的截图默认自动写入图片剪贴板，在支持的应用中直接按 Command-V 粘贴。截图设置或齿轮菜单可关闭；选择“立即收集”可以跳过等待系统浮动预览。
- 历史截图和手动导入不会覆盖剪贴板。连续截图保留最新一张；用户随后复制其他内容、暂停、关闭选项或锁屏，会使旧复制任务失效。取消 AirDrop 保留截图。

验证覆盖截图持久化、独立剪贴板并发时序、原生拖放、模拟 AirDrop 取消和成功回调、隐私、Pin 与鼠标穿透，以及中英文渲染和完整构建。测试不向手机或 iPad 发送文件，真实送达仍需选择设备后验证。本版本继续使用实验性的 ad-hoc 应用签名，更新后可能需要刷新系统窗口控制权限。
