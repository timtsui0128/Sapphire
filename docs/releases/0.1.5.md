# Sapphire Personal 0.1.5 — Safer sign-in and readable glass panels

## English

- Verify the Mac login password inside the process with OpenDirectory, so it no longer appears in a child process's command line. Encrypted archives now open in macOS Archive Utility, which collects their passwords itself and manages their extraction destination/progress.
- Store Spotify/TIDAL tokens and Spotify session cookies in the login Keychain. Existing preference values are removed after successful migration. New credentials are never written to preferences; if Keychain storage fails, they remain available only for that session.
- Bind Spotify authorization to a single, expiring PKCE/state transaction. Apply the same callback validation to TIDAL, and ignore login/refresh results arriving after logout or a newer login. Avoid logging authorization URLs and raw token-error responses.
- Escape quotes, backslashes and control characters in message/contact text inserted into AppleScript.
- Move expanded translucent-panel controls below the macOS menu bar. Use native frosted blur with a light/dark tint to separate widgets from desktop text, and use an opaque surface for Reduce Transparency or Increase Contrast. Preserve the attached panel's curved outline and the floating island's bottom toolbar.

Validation includes synthetic credential migration/failure cases, actual token-exchange methods with suspended fake networking, callback abuse cases, script-literal round trips, theme rendering, screen fitting and Pin interactions. No real account login, Mac-password authentication, message sending or installed-app automation is performed by these checks. Apple Developer ID signing and notarization remain unavailable; Sparkle update signatures are a separate protection. See [security notes](../security-hardening.md).

## 简体中文

- Mac 登录密码改用 OpenDirectory 在进程内验证，不再出现在子进程命令行中。加密压缩包交由 macOS“归档实用工具”收取密码和解压，目标文件夹与进度由系统工具管理。
- Spotify／TIDAL 令牌与 Spotify 会话 Cookie 改存登录钥匙串；旧偏好设置中的凭据在迁移成功后删除。新凭据不会写回普通偏好设置，钥匙串写入失败时仅在本次运行中保留。
- Spotify 登录增加一次性、有时限的 state／PKCE 绑定；TIDAL 共用严格的回调校验。退出或重新发起登录后，迟到的登录／刷新响应不能恢复旧账号；不再打印授权网址或原始令牌错误内容。
- 补齐消息与联系人内容写入 AppleScript 时的引号、反斜线和控制字符转义。
- 半透明展开面板的按钮下移到 macOS 菜单栏下方；改用原生磨砂模糊和明暗底色，减少桌面文字透出。开启“降低透明度”或“增强对比度”时使用不透明背景，保留原有圆角轮廓及胶囊底部工具栏。

验证覆盖假凭据迁移和失败处理、实际令牌兑换方法的延迟响应、无效回调、脚本文本转义、主题渲染、屏幕适配及 Pin 操作。测试不会登录真实账号、验证真实 Mac 密码、发送消息或操作已安装的应用。Developer ID 正式签名与 Apple 公证仍未完成，Sparkle 更新签名是另一层保护。详见[安全说明](../security-hardening.md)。
