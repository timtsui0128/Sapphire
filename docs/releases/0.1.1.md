# Sapphire Personal 0.1.1 — Quick AirDrop

## English

- Drag files, folders, images, web links, or text onto Sapphire's new menu-bar share icon to open macOS AirDrop.
- Click the icon to choose files or share clipboard content. Enable or hide it in Settings → File Shelf.
- Select multiple screenshots in the shelf and click AirDrop to share them together.
- Cancelled or failed shares keep screenshots. The existing screenshot retention setting is applied only when the system reports sharing success.
- Hide the entry point and cancel queued preparation while the session is locked. Includes English/Simplified Chinese and an older-system icon fallback.

Inspired by [Menu Drop by Sindre Sorhus](https://sindresorhus.com/menu-drop), independently implemented with public AppKit APIs. You choose the receiving device in the system window. No Menu Drop code or assets are included.

Validated with native pasteboard/drag checks using simulated sharing sessions, screenshot regressions, localization, appearance rendering, and a complete Apple Silicon build. These checks do not send files to another device. Real device discovery and delivery are handled by macOS.

## 简体中文

- 新增菜单栏分享图标，拖入文件、文件夹、图片、链接或文字即可打开 macOS 隔空投送。
- 点击图标可选择多个文件或分享剪贴板内容，在“设置 → 文件架”开关图标。
- 截图架多选截图后点 AirDrop，可以一次分享多张。
- 取消或失败保留截图；系统报告成功后才按截图原有保存策略处理。
- 锁屏时隐藏入口并取消尚未完成的准备。支持中英文和旧版系统的分享图标。

交互灵感来自 Sindre Sorhus 的 Menu Drop，使用公开 AppKit 接口独立实现，未包含其代码或素材。接收设备由你在系统窗口里选择。原生检查使用模拟分享会话，没有实际向其他设备发送文件。
