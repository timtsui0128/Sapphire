# TopLet 0.1.10 — Deliberate window snapping

## English

- Snap layouts now open only after dragging to the small top-center area of the current display and dwelling for the configured Activation Delay (default 0.45 seconds). Ordinary window movement no longer expands the panel or enables pointer capture. Command release follows the same regional delay.
- This personal test build switches from ad-hoc signing to a persistent Apple Development certificate. The first update may require one new Accessibility/window-control authorization. Future builds reuse the signing identity; missing certificates or changed release identity stop the build instead of silently resetting it. This is not a Developer ID/notarized distribution build.
- The application and new downloads are named TopLet. Sparkle preserves an existing installation's filename; if Finder still shows Sapphire.app, fully quit it, rename that same app to TopLet.app, and reopen it. Settings and screenshots remain in their existing storage.
- English and Simplified Chinese activation descriptions explain the top-center trigger. File drops retain the AirDrop and Copy to Clipboard destinations.

Validation covers trigger geometry on main/left/stacked displays, real dwell/cancel/release timing, window-placement regression checks, independent file-drop/clipboard and localization checks, and application/signature verification. Same-identity builds are checked separately; real window-control permission retention still needs a subsequent update on the user's Mac.
