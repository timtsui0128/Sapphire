# TopLet 0.1.19

Fixes an intermittent problem dragging window title bars after switching away from TopLet. The island’s hover panel lets mouse presses through, and TopLet clears the drag state even if macOS misses the release. Closing the island respects the app you switched to.

## 简体中文

修复了从 TopLet 切回 Chrome、Finder 等应用后，偶尔拖不动窗口标题栏的问题。刘海的悬停检测层会让鼠标按下事件穿过，即使 macOS 漏发松手事件，TopLet 也会结束这次拖动。收起刘海时，焦点会留在你刚切换到的应用。
