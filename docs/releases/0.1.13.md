# TopLet 0.1.13 — Restore Snap Zones activation

## English

- Fixes Snap Zones failing to appear when a global mouse monitor is installed but stops delivering motion during a native window drag. Confirmed window drags now also sample cursor position, so moving into the inset activation region no longer depends on entering the small hover probe or receiving another Accessibility notification.
- Keeps the existing gestures: pause at the center just below the menu bar to open layouts; continue to the physical top edge to hand the drag to Mission Control. Sampling does not arm or enlarge the transparent input area.
- Detects release even without a mouse-up event, stops sampling, and allows the next drag to activate normally. File AirDrop/Clipboard routing and the existing signing identity are retained.

An offscreen native-window regression reproduces the missed-event failure on the pre-fix code, then verifies dwell, quick crossings, release, handoff and next-drag recovery with the fix. Window placement, file-drop/clipboard, localization and full-build checks are included. These checks do not replace testing the installed app with real windows and Mission Control. This is still a personal Apple Development-signed test build without Apple notarization.

## 简体中文

- 修复拖窗口上去后分屏选项完全不出现的问题：全局鼠标监听器即使创建成功，也可能没有继续报告窗口拖动；现在会在确认窗口正在拖动时补充位置采样，让菜单栏下方的触发区正常收到位置。
- 操作保持一致：拖到菜单栏下方正中并停留，展开分屏；继续拖到屏幕最顶边，交给 Mission Control。采样不会扩大透明鼠标区域或接管输入。
- 即使没有收到松手事件，也会检测按键释放并停止采样；下一次拖动可以重新触发。保留文件 AirDrop／剪贴板功能及固定签名身份。

离屏原生窗口测试已复现修复前的失败路径，并验证修复后的停留触发、快速经过、松手、系统让出及下次拖动恢复。检查同时覆盖窗口放置、文件拖放／剪贴板、本地化与完整构建；实际窗口和 Mission Control 的体验仍需安装后确认。本版本仍为未经 Apple 公证的个人测试版。
