# iCloud calendars and class timetables / iCloud 日历与课表

TopLet reads the calendar accounts already configured in macOS, including iCloud, school accounts, and subscriptions. Add the timetable to Apple Calendar first. If your school provides a subscription link, use **Calendar → File → New Calendar Subscription** and select iCloud as the location to use it across Apple devices.

In **TopLet Settings → Calendar → Calendar Sources**, allow calendar access. **Follow Apple Calendar** uses the system Calendar selection. **Choose Calendars** lets you show only the timetable, regardless of the Apple Calendar selection. The choice applies to the notch widget, expanded agenda and calendar live activities. The expanded agenda shows the calendar name, start/end time and location when available.

TopLet uses the local calendar database, reloads after calendar changes, and can ask macOS to refresh its sources using the refresh button. No separate iCloud sign-in is needed. This integration does not edit or upload events. Reminders access is optional and separate. Subscription refresh timing depends on Apple Calendar and the school provider.

先确认课表在 Mac 的「日历」App 里可见。如果学校提供订阅链接，可在「日历 → 文件 → 新建日历订阅」中添加；位置选 iCloud 即可在同一 Apple 账户的设备间同步。参考 [Apple 的日历订阅说明](https://support.apple.com/en-ie/102301)。

打开 **TopLet → 设置 → 日历 → 日历来源**，点击「允许访问日历」。「跟随 Apple 日历」沿用系统日历选择；「选择日历」可点「取消全选」，再只勾你的课表。刘海日历、展开的日程和实时活动会采用该选择。展开后可查看课程的时间、所属日历和地点（原事件有填写时）。

TopLet 读取 Mac 上已经同步的数据，无需另登 iCloud。日历变动后会自动更新，也可点击日历来源右上的刷新按钮。此功能不会改写或上传课表；提醒事项权限可跳过。学校订阅的数据更新速度仍由系统日历和学校来源决定。
